# 研究方向选择建议

> 基于对 Tri Dao 研究脉络的全面分析，为进一步研究探索提供方向选择建议

---

## 五大可探索方向总览

| 方向 | 成熟度 | 开放空间 | 入门难度 | 工业价值 | 推荐指数 |
|------|--------|---------|---------|---------|---------|
| A. SSM 理论深化与创新 | 中 | 大 | 高 | 中 | ★★★★☆ |

## 方向 A：SSM 理论深化与创新

### 推荐理由
Mamba-3 (2026) 引入复数状态转移，但 SSM 的理论空间远未穷尽：
- 复数状态空间的表达能力边界尚未厘清
- 选择性机制的数学基础 (Haar 小波, 函数逼近) 仍需深化
- SSM 的缩放规律 (scaling law) 缺乏系统研究

### 具体课题
1. **复数状态空间模型**: Mamba-3 开辟的方向，复数 SSM 的表达能力、训练稳定性、效率权衡
2. **SSM scaling law**: 类似 Chinchilla 对 Transformer 的研究，SSM 的数据/参数/计算最优配比
3. **选择性机制泛化**: 超越 S6 的更灵活选择性方案 (如多头选择性、层级选择性)
4. **SSM 与其他架构的统一**: SSM 与 RNN、CNN、Attention 的统一理论框架

### 入门路径
1. 精读 HiPPO → S4 → Mamba → Mamba-2/SSD → Mamba-3
2. 理解状态空间方程: x'(t) = Ax(t) + Bu(t), y(t) = Cx(t) + Du(t)
3. 学习结构化矩阵理论 (DPLR, QR 分解)
4. 阅读 ICML 2025 Input Selectivity 论文

### 风险与挑战
- 理论门槛较高，需扎实的数学功底
- 纯理论创新的验证周期较长
- 与工业界直接需求可能有距离

---

## 方向 B：视觉 SSM 扩展（强烈推荐）

### 推荐理由
视觉 SSM 是 Mamba 应用扩展中最活跃、开放问题最多的方向：
- 2D/3D 扫描策略远未解决 (QuadMamba、LocalMamba 只是初步探索)
- 视频 SSM 几乎空白
- 多模态 SSM (视觉-语言) 刚起步
- 医学影像 (2DMamba)、遥感、点云等领域有大量应用空间

### 具体课题
1. **视频 SSM**: 时序维度的选择性扫描策略，视频理解中的长程依赖建模
2. **多模态 SSM**: 视觉-语言融合的 SSM 架构 (MambaVL 方向延伸)
3. **3D SSM**: 点云、NeRF、Gaussian Splatting 中的 SSM 应用
4. **医学影像 SSM**: 病理切片、CT/MRI 等大尺寸医学图像的 SSM 建模
5. **高效视觉 SSM**: 针对边缘设备的轻量 SSM 设计
6. **SSM 检测/分割**: 将 SSM 用于目标检测、语义分割等下游任务

### 入门路径
1. 精读 Vim → VMamba → QuadMamba → Demystify Mamba in Vision
2. 理解 1D → 2D 扫描的核心挑战 (空间局部性 vs 全局依赖)
3. 在 ImageNet/COCO/ADE20K 上复现 Vim 或 VMamba
4. 探索新的扫描策略或跨模态融合方案

### 优势
- 应用场景丰富，容易找到有意义的课题
- 可与视觉-语言大模型 (VLM) 结合
- 实验验证周期短，容易出论文
- 工业界 (自动驾驶、医学影像) 需求明确

---

## 方向 C：SSM-Transformer 混合架构（强烈推荐）

### 推荐理由
纯 SSM 在 COPY、ICL、CoT 推理上存在已知局限，混合架构是兼顾效率与能力的实践最优解：
- Jamba 已验证混合方案在大规模 (>50B) 上的可行性
- 最优混合策略 (比例、位置、路由) 仍不明确
- 不同任务对 SSM/Attention 需求的动态调度几乎未探索

### 具体课题
1. **自适应混合架构**: 根据输入动态选择 SSM 层或 Attention 层
2. **混合架构 scaling law**: SSM:Attention 比例随规模变化的最优解
3. **任务感知混合**: 不同任务 (代码、数学、长文本) 的最优混合配置
4. **SSM-Attention 统一视角**: 从 SSD 对偶理论出发设计真正统一的层
5. **长上下文混合**: 256K+ 上下文中 SSM 与 Attention 的最优配合

### 入门路径
1. 精读 Mamba-2/SSD → Jamba → An Empirical Study of Mamba-based LMs
2. 理解 SSD 理论: SSM 与 Attention 的数学对偶
3. 在小/中规模 (1B-8B) 上实验混合比例
4. 分析不同任务上 SSM vs Attention 的表现差异

### 优势
- 工业界极度关注 (所有大模型公司都在探索)
- 理论 (SSD) + 实验 (Jamba) 双重支撑
- 可以从小规模实验开始，逐步扩展
- 兼顾效率 (SSM) 与能力 (Attention)

---

## 方向 D：高效注意力新范式

### 推荐理由
FlashAttention 已趋成熟 (FA4)，但注意力效率创新远未终结：
- 线性注意力、稀疏注意力仍在快速发展
- Log-Linear Attention (ICLR 2026) 开辟新方向
- 新硬件 (Blackwell 及之后) 持续带来新优化空间

### 具体课题
1. **对数线性注意力**: Log-Linear Attention 方向的深化
2. **动态稀疏注意力**: 输入自适应的稀疏模式选择
3. **超低精度注意力**: FP4 甚至更低位宽的注意力计算
4. **非 GPU 架构注意力**: TPU、LPU、专用 ASIC 上的注意力优化
5. **注意力 + SSM 统一内核**: 用一套内核同时支持 Attention 和 SSM

### 入门路径
1. 精读 FA1→FA2→FA3→FA4 全系列
2. 学习 FlexAttention 编程模型
3. 阅读 Native Sparse Attention (ACL 2025 Best Paper)
4. 学习 Triton/CUDA 内核编程

### 风险与挑战
- 技术门槛极高 (需深入 GPU 架构)
- 竞争激烈 (工业界主导)
- 新方向需要跟随硬件迭代
- 纯算法创新空间在收窄

## 方向 E：SSM 可解释性与理论分析

### 推荐理由
SSM 作为新兴架构，其内部机制理解远不如 Transformer 深入：
- Mamba 的选择性门控机制如何决定信息保留/遗忘
- SSM 内部的信息流路径与 Transformer attention map 的对比
- SSM 的失败模式 (COPY/CoT 局限) 的根因分析

### 具体课题
1. **SSM 机制可解释性**: 类似 mechanistic interpretability 对 Transformer 的工作
2. **SSM 失败模式分析**: COPY/ICL/CoT 局限的理论解释与修复
3. **SSM 表达能力边界**: 什么函数/任务 SSM 能学好，什么学不好
4. **SSM 与 Transformer 对比分析**: 从信息论、计算复杂度等维度系统比较

### 入门路径
1. 阅读 Understanding Input Selectivity in Mamba (ICML 2025)
2. 阅读 Exploring the Limitations of Mamba in COPY and CoT (EMNLP 2025)
3. 阅读 Interpreting and Steering SSM via Activation Subspace (2025)
4. 学习 mechanistic interpretability 方法论

### 优势
- 学术价值高，理论贡献明确
- 竞争相对较少 (分析类研究门槛在知识而非工程)
- 成果对架构改进有直接指导意义

### 风险
- 工业界直接需求有限
- 需要较好的理论功底
- 实验设计难度较高

---

## 综合推荐：基于不同目标的路径选择

### 如果你的目标是「快速发论文」
**首选方向 B (视觉 SSM) 或方向 C (混合架构)**
- 视觉 SSM 应用空间大，容易找到创新点
- 混合架构实验可从小规模开始，对比清晰
- 两个方向都有明确的理论基础和实验基线

### 如果你的目标是「深入理论」
**首选方向 A (SSM 理论) 或方向 E (可解释性)**
- SSM 理论仍处快速发展期
- 可解释性是理解模型本质的关键
- 两者都能产生高引用的理论贡献

### 如果你的目标是「工业界价值」
**首选方向 C (混合架构) 或方向 D (高效注意力)**
- 混合架构是所有大模型公司关注的焦点
- 高效注意力直接关系到训练/推理成本
- 两者都有明确的工程落地场景

### 如果你的目标是「跨学科应用」
**首选方向 B (视觉 SSM) 中的医学影像/遥感子方向**
- 2DMamba 已证明 SSM 在大尺寸图像上的潜力
- 医学影像、遥感等领域对长序列建模有天然需求
- 跨学科合作机会多

## 下一步行动建议

1. **选定 1-2 个方向**，深入阅读该方向的核心论文 (先读综述，再读原文)
2. **复现基线模型**，在标准数据集上跑通实验
3. **找到开放问题**，在复现过程中发现可改进的点
4. **小规模验证**，用实验验证初步想法
5. **扩展规模**，在更大规模上验证有效性

### 推荐阅读顺序 (通用)
1. HiPPO (NeurIPS 2020) — 理解 SSM 起源
2. S4 (ICLR 2022) — 理解结构化状态空间
3. FlashAttention (NeurIPS 2022) — 理解高效注意力
4. Mamba (COLM 2024) — 理解选择性 SSM
5. Mamba-2/SSD (ICML 2024) — 理解 SSM-Attention 对偶
6. 根据选定方向深入阅读对应论文
