I 文献综述

本综述覆盖三个交叉领域的最新进展：3D SSM（状态空间模型）、B-Rep 深度学习、FEA 仿真与深度学习。三者的交汇处存在一个明确的研究空白——尚无人将 SSM 应用于 B-Rep 拓扑结构，而这恰恰是工业 3D 模型最自然的数据表示。

1.1 3D SSM：序列化方法的演进谱系

3D SSM 的核心挑战在于：SSM 是 1D 序列处理器，而 3D 数据（点云、体素、网格）天然无序。所有 3D SSM 研究的第一步都是序列化——将 N 维数据映射为 1D 序列。以下按序列化策略的复杂度递进梳理核心论文。

1.1.1 空间填充曲线方法

PointMamba（NeurIPS 2024）[链接]

  • 序列化：Hilbert 曲线 + Trans-Hilbert 曲线，从不同方向扫描关键点生成两种 token 序列
  • 架构：非分层 Mamba 编码器，N 个 Mamba block（LN + Selective SSM），支持 MAE 式自监督预训练
  • 数据集：ModelNet40、ScanObjectNN、ShapeNetPart
  • 性能：ModelNet40 上超 Point-MAE 0.4%；显著降低 GPU 内存和 FLOPs
  • 局限：单方向因果建模，对输入顺序高度敏感；仅两种序列化方式
  • 开源：是（GitHub）

CloudMamba（AAAI 2026）[链接]

  • 序列化：序列扩展与合并（Sequence Expanding & Merging）——沿每个坐标轴分别序列化点，因果推理后合并，比 Hilbert 曲线更稳定
  • 核心创新：GS6（Grouped Selective State Space）——按维度分组共享参数（分组率=3），缓解 S6 的过拟合问题
  • 架构：Hexa-orientation Mamba Block（含 ChainedMamba）+ Downsampling/Upsampling
  • 数据集：ModelNet40 (93.65% OA)、ScanObjectNN、ShapeNet、S3DIS
  • 开源：是（GitHub）

HydraMamba（ACM MM 2025）[链接]

  • 序列化：Shuffle Serialization——将 Hilbert 曲线 6 种变体随机分配给不同层，每层从不同视角推断结构
  • 核心创新：ConvBiS6 层（双向 S6 + 1D grid 卷积分支）+ MHS6（多头 S6）
  • 数据集：ModelNet40、ShapeNet、S3DIS
  • 开源：是（GitHub）

1.1.2 可微/可学习序列化方法

DM3D（Deformable Mamba）（NeurIPS 2026）[链接]

  • 序列化：Offset-guided Gaussian Sequencing——将序列化视为连续优化过程，而非离散 token 重排
  • 核心机制：
    • DSR（可变形空间重采样）：OffsetNet 预测空间偏移量 Δp，引导 Gaussian-based KNN 重采样
    • GDR（高斯可微重排序）：预测序列偏移量 Δt，通过 Gaussian kernel 分配 token 特征到近邻位置
  • 架构：三 SSM 分支——F-SSM（前向）、C-SSM（通道翻转后向）、D-SSM（可变形，核心）
  • 创新点：CASU（连续性感知状态更新）+ Tri-Path Fusion
  • 数据集：ModelNet40、ScanObjectNN、ShapeNetPart（SOTA/competitive）

StruMamba3D（ICCV 2025）[链接]

  • 核心创新：为 SSM 隐藏状态赋予空间位置属性（spatial states），作为点间空间依赖的代理
  • 序列长度自适应：缓解预训练与下游任务之间的序列长度差异
  • 性能：ModelNet40 达 95.1%；ScanObjectNN 最难 split 达 92.75%；ShapeNetPart mIoU 85.0%
  • 亮点：四个下游任务 SOTA，是目前 3D 点云 SSM 的最强结果之一

1.1.3 混合架构方法

PointLAMA（2025）[链接]

  • 序列化：任务感知——分类用 Hilbert 曲线，分割用轴排序
  • 核心创新：PMLA（Point-wise Multi-head Latent Attention），与 Mamba 共享 latent space，增强局部上下文建模
  • 预训练：条件扩散——对扰动特征序列进行 denoising，不依赖显式点级重建
  • 性能：ModelNet40 达 94.5%（超 PointMamba 0.9%）；ShapeNetPart 85.5% mIoU（自监督 SOTA）
  • 局限：未公开代码；缺乏效率分析

Pamba / MambaD（AAAI 2025）[链接]

  • 序列化：多路径序列化——不同路径分配给不同 block
  • 核心创新：ConvMamba Block——卷积与 Mamba 结合，补偿 Mamba 局部几何建模和单方向建模的不足
  • 数据集：ScanNet v2、ScanNet200、S3DIS、nuScenes（语义分割 SOTA）

1.1.4 时空 4D 与结构化数据方法

UST-SSM（2025）[链接]

  • 序列化：STSS（时空选择扫描）——prompt-guided clustering 将时空距离远但语义相似的点聚类 → 簇内 Hilbert 排序 → 沿时间维度扫描
  • 创新：STSA（时空结构聚合，4D KNN 邻域传播）+ TIS（时间交互采样，扩展时间感受野）
  • 数据集：MSR-Action3D、NTU RGB+D（3D 动作识别）、Synthia 4D（4D 语义分割）
  • 开源：是（GitHub）

Mamba4D（CVPR 2025）[链接]

  • 架构：时空解耦——Intra-frame Spatial Mamba（帧内空间维编码局部几何）+ Inter-frame Temporal Mamba（帧间时间维传递 token）
  • 亮点：纯 SSM 4D backbone，线性复杂度

Voxel Mamba（NeurIPS 2024）

  • 序列化：Group-free 策略——整个体素空间通过 Hilbert 曲线序列化为单一序列
  • 创新：Dual-scale SSM Block 扩大 1D 曲线上的感受野
  • 数据集：Waymo Open Dataset、nuScenes（3D 目标检测）
  • 开源：是（GitHub）

MeshMamba（2025）[链接]

  • 序列化：基于身体部位 UV 映射和模板网格 3D 坐标的顶点序列化
  • 应用：3D articulated mesh 生成（MambaDiff3D）+ 人体网格重建（Mamba-HMR）
  • 亮点：可处理 10,000+ 顶点的人体网格

Mamba-CAD（AAAI 2025）[链接]

  • 序列化：将参数化 CAD 命令序列（CSG 表示）视为离散语言序列，固定长度 N=128
  • 架构：基于 Mamba 的 encoder-decoder + CAD 重建预训练 + GAN latent 生成
  • 数据集：自建 77,078 个 CAD 模型；命令数 61-128
  • 关键局限：仅处理 CSG 表示，明确排除 B-Rep——论文指出 B-Rep 缺乏构建历史，难以参数化为命令序列

关键观察

所有 3D SSM 方法都在与"无序数据的序列化"搏斗——用 Hilbert 曲线、坐标轴排序、可微偏移、prompt 引导聚类等手段将无序变有序。但没有任何方法利用 B-Rep 拓扑结构作为序列化依据。Mamba-CAD 是最接近的，但明确排除了 B-Rep。

1.2 B-Rep 深度学习：从图网络到 Transformer

B-Rep（Boundary Representation）是 CAD 领域的标准数据结构，通过面（Face）、边（Edge）、顶点（Vertex）及其拓扑关系来描述 3D 实体。与点云不同，B-Rep 天然包含拓扑连接关系——这为序列化提供了结构化的基础。

1.4 研究空白分析

核心发现：B-Rep + SSM = 明确的研究空白

三个领域调研揭示了一个清晰的交叉空白：

维度 3D SSM 现状 B-Rep 深度学习现状 交叉空白
数据表示 点云、体素、网格 B-Rep 拓扑（face/edge/coedge） 无 SSM 处理 B-Rep
序列化方法 Hilbert 曲线、坐标排序、可微偏移 BFS face 遍历、coedge 拓扑遍历 拓扑序列化 + SSM 未结合
模型架构 Mamba block、双向 SSM、ConvMamba GNN、Transformer、扩散模型 B-Rep 上无 SSM 架构
工业任务 通用 3D 分类/分割 CAD 分类、特征识别、生成 工业 CAD + SSM 未探索

为什么 B-Rep 拓扑是 SSM 的天然序列？

3D 点云 SSM 的核心痛苦是无序数据的人为序列化——Hilbert 曲线、坐标排序都是"强行"赋予顺序，与数据的内在结构无关。而 B-Rep 天然包含拓扑顺序：

  • Coedge 遍历序：B-Rep 的 coedge（有向半边）构成环（loop），沿环遍历本身就是有序的——面边界天然是一个序列
  • Face 邻接序：通过 BFS/DFS 遍历 face-adjacency graph，得到面的有序序列（AutoBrep 已用 BFS 序列化）
  • UV 参数序：每个面的 UV 参数域天然有序（UV-Net 已将面编码为 UV 网格）
  • 建模操作序：CAD 模型的创建过程本身是有序的（拉伸、旋转、倒角等操作序列）
核心假设

利用 B-Rep 拓扑关系作为 SSM 的序列化依据，可以避免点云 SSM 中"无序数据人为序列化"的根本矛盾，同时保留 SSM 的线性复杂度优势。这是一个从"无序 → 有序"到"天然有序 → 序列化"的范式转变。

II 实验方案

2.1 研究问题与总体假设

研究问题：能否利用 B-Rep 拓扑结构作为 SSM 的天然序列化依据，设计出在工业 CAD 任务（分类、特征识别、分割）上兼具效率（线性复杂度）和精度（超越 GNN/Transformer 基线）的 3D 模型分析架构？

核心假设（H1）：B-Rep 拓扑遍历序（coedge 环序 / face BFS 序）作为 SSM 输入序列，优于 Hilbert 曲线等人为序列化策略，因为前者保留了数据的内在拓扑关系。

辅助假设（H2）：SSM 的隐藏状态可以编码 B-Rep 拓扑传播（类似 GNN 的消息传递），但以 O(n) 复杂度实现，在面数较多的大模型上效率优于 O(n²) 的 Transformer。

辅助假设（H3）：将 SSM 用于 FEA 仿真时序数据（时变物理场），可以替代 MeshGraphNet 的逐时间步图消息传递，以线性复杂度建模长时序依赖。

2.2 实验分阶段设计

1 Phase 1：B-Rep 拓扑序列化策略（验证 H1）

目标

设计并对比多种 B-Rep 拓扑序列化策略，验证"拓扑序优于人为序"的假设。

序列化策略设计

策略 ID 名称 原理 预期优势
S1 Coedge-Loop Scan 沿每个面的 coedge 环遍历，将面边界曲线的采样点排列为序列；面间按 BFS 序连接 保留面边界拓扑完整性
S2 Face-BFS Scan 在 face-adjacency graph 上 BFS 遍历，每个面编码为 UV 网格特征向量，面序列输入 SSM 最接近 AutoBrep 的序列化方式
S3 Topology-Geometry Interleaved Scan 交替序列化拓扑信息（face type, edge convexity）和几何信息（UV grid），让 SSM 同时获取两者 拓扑与几何信息融合
S4（基线） Hilbert Point Scan 从 B-Rep 采样点云，用 Hilbert 曲线序列化（PointMamba 方法） 对照：人为序列化
S5（基线） Random Scan 面随机排列 对照：无序基线

实验设置

  • 骨干网络：标准 Mamba block（6 层，hidden=256），统一架构，仅序列化策略不同
  • 数据集：Fusion 360 Gallery（35,858 模型，8 类 face 分割）
  • 评估指标：Face 分类准确率、IoU、序列化耗时
  • 对比：S1-S3 vs S4-S5，Friedman 检验评估序列化策略对性能的显著性

预期结果

S1/S2（拓扑序）应显著优于 S4（Hilbert）和 S5（随机），证明 B-Rep 拓扑天然有序性确实有利于 SSM 的序列建模。

2 Phase 2：BRepMamba 架构设计与评估（验证 H1 + H2）

目标

设计完整的 BRepMamba 架构，在多个 CAD 任务上与 GNN 和 Transformer 基线全面对比。

架构设计

输入: B-Rep 模型 │ ├─ Face Encoder (UV-Grid CNN → 64d embedding, 复用 UV-Net 的面编码器) ├─ Edge Encoder (1D CNN on UV curve → 64d) ├─ Topology Encoder (coedge adjacency → topology features) │ ▼ Topology-aware Serialization Module │ (Phase 1 选出的最优策略, 如 S1: Coedge-Loop + Face-BFS) │ ▼ Token Sequence: [face_1, face_2, ..., face_n] │ 每个 face token = UV-Grid embedding ⊕ topology embedding │ ▼ Bidirectional Mamba Blocks × 6 │ (双向 SSM: 前向 + 后向, 融合两个方向的隐藏状态) │ (GS6 分组参数共享, 缓解过拟合 — 借鉴 CloudMamba) │ ▼ Task Heads: ├─ Classification: Global pooling → Linear ├─ Segmentation: Per-face prediction (face-level mIoU) └─ Feature Recognition: Per-face multi-class

关键设计决策

设计点 选择 理由
方向性 双向 Mamba B-Rep 拓扑无因果方向，双向扫描消除方向偏差（借鉴 VSSD 非因果思想）
局部增强 ConvMamba Block B-Rep 面间局部几何依赖需要卷积分支补偿（借鉴 Pamba 的 ConvMamba）
参数共享 GS6 分组共享 B-Rep face 特征维度多（UV grid 64d + topology 32d），GS6 防过拟合（借鉴 CloudMamba）
空间状态 Spatial State Injection 为隐藏状态赋予 face 的 3D 质心坐标，增强空间依赖建模（借鉴 StruMamba3D）

评估任务与数据集

任务 数据集 指标 基线方法
Face 分类/分割 Fusion 360 Gallery (35,858 模型) Accuracy, IoU BRepNet (92.52%/77.10%), UV-Net, BRepFormer, PointNet++
加工特征识别 MFCAD++ (15,488+ 模型) Accuracy, IoU BRepNet, UV-Net (77.87%/89.03%), BRepGAT
CAD 分类 SolidLetters (26 类) Accuracy UV-Net (97.24%), PointNet, DGCNN
大规模预训练 ABC Dataset (100 万+ 模型) 下游迁移性能 MTM 自监督, Brep2Shape

效率对比实验

  • 记录参数量、FLOPs、推理延迟、GPU 显存占用
  • 特别关注面数 scaling：在 face 数 = 50, 100, 200, 500, 1000 的模型上测效率
  • 预期：SSM 的 O(n) 在大模型上显著优于 Transformer 的 O(n²)
3 Phase 3：FEA 时空代理模型（验证 H3）

目标

将 SSM 扩展到 FEA 仿真时序数据，用 SSM 替代 MeshGraphNet 的逐时间步图消息传递，建模时变物理场。

问题定义

给定 CAD 模型的 B-Rep 结构和边界条件，预测 FEA 仿真在多个时间步上的物理场（如应力场、位移场、温度场）。

架构设计：BRepMamba-FEA

输入: B-Rep 模型 + 边界条件 + 材料属性 │ ▼ Phase 2 的 BRepMamba Encoder → 面级特征序列 │ ▼ Spatial Mamba (帧内): 在每个时间步对面序列做空间建模 │ ▼ Temporal Mamba (帧间): 沿时间维度传递隐藏状态 │ (借鉴 Mamba4D 的时空解耦设计) │ ▼ Decoder: 面级特征 → 节点级物理场预测 │ (通过 UV grid 反映射到面表面)

实验设置

项目 设置
数据集 DrivAerML (500 变体, CFD 场数据) + 自建 FEA 数据集（结构力学）
基线 MeshGraphNet, X-MeshGraphNet, FR-Mamba (FNO+Mamba)
评估指标 相对 L2 误差、推理加速比（vs FEA 求解器）、长时序稳定性
关键实验 时间步数 = 10, 50, 100, 200, 500 时的精度与效率对比

预期优势

  • SSM 的线性复杂度在长时序（200+ 步）上应优于 MeshGraphNet 的逐步 GNN
  • B-Rep 拓扑序作为空间扫描策略，比 DrivAerML 的 STL 点云 k-NN 图更有结构信息
  • FR-Mamba 已验证 FNO+Mamba 可行，本方案进一步用 B-Rep 拓扑替代 FNO 的空间建模
4 Phase 4：理论分析与可解释性（补充）

目标

分析 BRepMamba 的隐藏状态与 GNN 消息传递的对应关系，建立理论桥梁。

分析内容

  • 消息传递对偶：SSM 的隐藏状态更新 h_t = A·h_{t-1} + B·x_t 与 GNN 的消息传递 m_v = Σ_{u∈N(v)} W·h_u 的数学关系——SSM 在序列上等价于 1D 因果图卷积，拓扑序使"1D 序列邻居"≈"图邻居"
  • 感受野分析：L 层 SSM 的感受野 = 序列全长（全局），而 L 层 GNN 的感受野 = L-hop 邻域（局部）——SSM 在拓扑序上天然有全局感受野
  • 信息保留分析：对比 B-Rep → 点云 → Hilbert 序列化 vs B-Rep → 拓扑序列化，量化信息损失
  • 注意力图对比：用 BRepFormer 的 attention map 与 BRepMamba 的隐藏状态激活做可视化对比

2.4 风险与应对

风险 描述 应对方案
B-Rep 序列化不连续 拓扑遍历序在面间跳转时可能产生序列不连续，影响 SSM 局部建模 引入 ConvMamba（卷积补偿局部性）+ 空间状态注入（face 3D 质心坐标）
B-Rep 数据获取困难 工业 B-Rep 数据集规模远小于 ImageNet/ShapeNet 使用 ABC Dataset (100 万+) 做大规模预训练 + 自监督（借鉴 MTM 的 Masked Topology Modeling）
SSM 精度不如 Transformer 纯 SSM 在部分任务可能不如 Attention 的全局建模能力 设计 SSM-Attention 混合层（借鉴 PointLAMA 的 Latent Attention），作为 fallback
FEA 数据集不足 公开 FEA+CAD 数据集稀缺 Phase 3 可先用 DrivAerML 验证可行性，同步自建小规模结构力学数据集
被竞争者抢先 3D SSM 领域发展快，可能有人先做 B-Rep + SSM 尽快完成 Phase 1 并发布预印本（arXiv），确立优先权；Phase 3/4 做差异化
