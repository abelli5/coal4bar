# 视觉 SSM 研究思考问题集

> 在阅读论文的过程中思考这些问题。问题分为三类：
> - 📐 **理解性问题** — 检验对论文核心内容的理解
> - 🔍 **对比性问题** — 跨论文比较，发现异同
> - 💡 **探索性问题** — 指向开放课题，可作为研究方向

---

## 一、1D → 2D：扫描策略的核心矛盾

### 📐 理解性问题

**Q1.** S4ND (NeurIPS 2022) 采用了什么方式将 1D SSM 扩展到 2D 图像？这种方式的数学基础是什么？它在哪些假设下会失效？

**Q2.** Vim 的双向扫描 (forward + backward) 和 VMamba 的四方向扫描 (四个对角方向) 在数学上有什么本质区别？它们的感受野形状分别是什么？

**Q3.** QuadMamba 的四叉树分区是"内容自适应"的。具体来说，模型如何决定在哪里进行分区？分区边界是硬的还是软的？如果是硬边界，会不会导致梯度不可导？

**Q4.** LocalMamba 使用了窗口化扫描。窗口内部的扫描是否还是标准的 Mamba selective scan？跨窗口的信息如何传递？与 Swin Transformer 的 shifted window 机制有何异同？

**Q5.** 2DMamba 声称实现了"真正的 2D 状态空间"。它的状态矩阵 A 是如何定义的？状态维度是 N×N（2D）还是两个独立的 N？如果 A 是 2D 的，如何保持高效计算？

### 🔍 对比性问题

**Q6.** 列出所有视觉 SSM 论文中使用的扫描策略：

| 论文 | 扫描方向数 | 扫描顺序 | 自适应？ | 跨窗口？ |
|------|-----------|---------|---------|---------|
| S4ND | ? | ? | ? | ? |
| Vim | ? | ? | ? | ? |
| VMamba | ? | ? | ? | ? |
| LocalMamba | ? | ? | ? | ? |
| 2DMamba | ? | ? | ? | ? |
| QuadMamba | ? | ? | ? | ? |

哪种策略在理论上最优？哪种在实际中表现最好？理论和实践之间有差距吗？为什么？

**Q7.** Vim 保留了 ViT 的 class token 和 position embedding，而 VMamba 没有保留 class token。这个设计差异背后的理由是什么？位置编码对 SSM 的作用与对 Transformer 的作用有何不同？

**Q8.** 将 Demystify Mamba in Vision 的分析框架应用到这里：哪种扫描策略最接近线性注意力？哪种最远离线性注意力？这个距离与性能有关吗？

### 💡 探索性问题

**Q9.** 所有现有扫描策略都是"人工设计"的（raster scan, 四方向, 四叉树等）。能否设计一种**可学习的扫描策略**，让模型自己决定如何遍历 2D 空间？这种策略如何保证：
- 全局覆盖性（每个位置都被访问）
- 空间局部性（相邻像素在序列中尽量靠近）
- 计算效率（不能退化为 O(N²)）

**Q10.** 视频是 3D 数据 (T×H×W)。如果要在视频上使用 SSM：
- 应该用 3D 扫描 (时间→空间) 还是分离的 2D+1D 扫描？
- 时间维度的因果性（只能看过去帧）和空间维度的非因果性如何统一？
- 现有 2D 扫描策略能否直接推广到 3D？计算复杂度会怎样变化？

**Q11.** 图像的"真实拓扑"不是 2D 网格而是 2D 流形（例如球面图像、全景图）。对于非 Euclidean 结构的数据，SSM 的扫描策略该如何定义？能否结合图神经网络的思想？

## 二、选择性机制在视觉中的意义

### 📐 理解性问题

**Q12.** Mamba 的选择性机制让 B(x), C(x), Δ(x) 变成输入依赖的。在视觉任务中，"选择性"意味着什么？模型在选择性"看"图像的哪些部分？能否可视化 SSM 的选择性模式（类似于 attention map）？

**Q13.** Understanding Input Selectivity (ICML 2025) 证明 Mamba 的 S6 层可以表示 Haar 小波投影。这对视觉任务有什么启示？Haar 小波在图像处理中天然存在（如 Haar wavelet transform），这是否意味着 SSM 在视觉中有特殊的数学优势？

**Q14.** Caduceus 为 DNA 序列设计了反转等变 (reverse equivariant) 的 SSM。在视觉中，存在哪些类似的对称性需求？
- 水平翻转等变性
- 旋转等变性
- 尺度等变性
能否设计等变视觉 SSM？等变约束会限制模型的表达能力吗？

**Q15.** Selective Visual Prompting 论文指出，微调 Vision Mamba 时存在"判别信息损失"。这是什么意思？SSM 的 forget gate 会不会遗忘对下游任务有用的信息？这与 Transformer 的预训练-微调差异在哪里？

### 🔍 对比性问题

**Q16.** Demystify Mamba in Vision 列出了 SSM 与线性注意力的六个差异（input gate, forget gate, shortcut, 无 normalization, single-head, block design）。对每个差异，思考：
- 这个差异在视觉任务中是有利的还是不利的？
- 如果移除这个差异（让 SSM 更像线性注意力），性能会上升还是下降？
- 有没有一个"最优组合"：保留某些 SSM 特性 + 引入某些注意力特性？

**Q17.** Attention 的优势在于 O(N²) 的全局交互，SSM 的优势在于 O(N) 的线性复杂度。但在视觉中，CNN 已经用局部感受野证明了局部性足够有效。SSM 相比 CNN 的优势是什么？相比 attention 相比 CNN 的优势又少了什么？

### 💡 探索性问题

**Q18.** SSM 的选择性可以理解为一种隐式的 attention。能否设计一种**显式的选择性可视化方法**，类似 attention rollout / attention flow，来理解 SSM 在视觉任务中关注了哪些区域？这种可视化能否用于：
- 诊断 SSM 的失败模式
- 指导架构改进
- 提供可解释性

**Q19.** 选择性机制让 SSM 可以动态选择信息。在视觉-语言多模态任务中（MambaVL 方向），能否设计一种**跨模态选择性路由**：让文本输入控制视觉 SSM 的扫描方向/权重？这比 cross-attention 有什么优势/劣势？

## 三、SSM 的局限性与视觉任务

### 📐 理解性问题

**Q20.** Exploring the Limitations of Mamba (EMNLP 2025) 指出 SSM 在 COPY 任务上有困难。在视觉任务中，什么是"COPY"的等价任务？
- 图像复制/重建？
- 密集预测（语义分割的逐像素分类）？
- 检测中的精确空间定位？
视觉 SSM 是否存在类似的局限性？有实验证据吗？

**Q21.** An Empirical Study (NVIDIA 2024) 发现在 ICL (in-context learning) 上 SSM 不如 Transformer。在视觉中，ICL 对应的是 few-shot 图像分类或视觉提示学习 (visual prompting)。Vision Mamba 在 few-shot 任务上的表现如何？有没有相关的实验数据？

**Q22.** ReMamba 通过"再处理"机制增强长序列能力。这个机制能否迁移到视觉？在视觉中，"再处理"意味着什么——对重要图像区域的二次扫描？对全局信息的重新编码？

### 🔍 对比性问题

**Q23.** 对比以下三种长序列建模方案在视觉任务上的优劣：

| 特性 | ViT (Attention) | Vim (SSM) | ConvNeXt (CNN) |
|------|----------------|-----------|----------------|
| 复杂度 | O(N²) | O(N) | O(kN) |
| 全局感受野 | ✓ | ✓ (但受状态大小限制) | ✗ (需要堆叠层) |
| 位置感知 | 强 | 弱？ | 强 (局部) |
| 平移等变性 | ✗ | ? | ✓ |
| 长距离依赖 | 强 | ? | 弱 |

SSM 在哪些维度上具有独特优势？哪些维度上存在明显劣势？

**Q24.** Interpreting and Steering SSM (ICML 2026) 发现了 SSM 中的"激活子空间瓶颈"。这个瓶颈在视觉 SSM 中是否同样存在？瓶颈是否与状态维度 N 有关？增大 N 能否缓解？

### 💡 探索性问题

**Q25.** 如果 SSM 在精确复制和空间定位上有局限，能否设计一种**混合策略**：用 SSM 处理全局/语义信息，用轻量 CNN 分支处理精确空间信息？这种设计比纯 SSM 或纯 Transformer 好在哪里？Jamba 的混合策略能给什么启示？

**Q26.** Mamba-3 引入了复数状态转移。在视觉中，复数状态是否有特殊意义？例如：
- 复数的模和辐角能否分别编码"强度"和"位置"信息？
- 复数 SSM 是否天然适合处理相位/频率信息（如 Fourier 域的图像处理）？
- 能否将 Mamba-3 直接应用于视觉任务，预期会有什么不同？

## 四、扫描效率与硬件感知

### 📐 理解性问题

**Q27.** Mamba 的选择性扫描算法是如何利用 GPU 硬件的？具体来说：
- 为什么选择性扫描不能用卷积形式（而 S4 可以）？
- 分块扫描策略如何减少 HBM 访问？
- 与 FlashAttention 的分块计算有什么异同？

**Q28.** 视觉 SSM 中，多种扫描方向（如 VMamba 的四方向）意味着同一张图被扫描四次。这导致：
- 计算量增加 4 倍？
- 内存增加 4 倍？
- 有没有方法在不损失信息的前提下减少扫描次数？

### 💡 探索性问题

**Q29.** FlashAttention 的核心思想是"IO-aware"。能否为视觉 SSM 设计类似的**IO-aware 扫描内核**？特别是：
- 多方向扫描能否合并为一次内存访问？
- 能否利用 GPU 的 2D 纹理内存来加速 2D 扫描？
- 自适应扫描（如 QuadMamba）的内存访问模式是否比固定扫描更差？

**Q30.** Log-Linear Attention (ICLR 2026) 提供了 O(N log N) 的复杂度。在视觉任务中，N = H×W (图像) 或 T×H×W (视频)。log N 的增量有意义吗？能否将 Log-Linear Attention 与 SSM 结合，在保持线性效率的同时获得更丰富的交互？

## 五、架构设计与创新空间

### 📐 理解性问题

**Q31.** Vim 和 VMamba 的 block 结构差异是什么？
- Vim block: Conv1d → SSM → gate → 投影
- VMamba VSS block: 深度卷积 → SS2D → 层归一化 → MLP
这些设计差异如何影响模型的表达能力和效率？

**Q32.** Jamba 在语言模型中使用了 Transformer-Mamba 交替层。如果将这种设计迁移到视觉：
- 应该在早期层还是晚期层使用 attention？
- 视觉任务中，哪些层最需要全局 attention（如分类头）？哪些层用 SSM 足够？
- 有没有实验数据支持某种混合比例？

**Q33.** VSSD 将 SSD 框架扩展到非因果视觉任务。非因果 SSD 的数学形式是什么？它如何处理"未来"信息？与 Vim 的双向扫描相比，VSSD 的优势在哪里？

### 💡 探索性问题

**Q35.** 能否设计一种**自适应架构路由**：根据输入图像的复杂度，动态决定每个位置使用 SSM 还是 attention？例如：
- 平滑区域（如天空）→ SSM 足够

这种设计能否在保持效率的同时提升精度？计算开销如何？

**Q36.** 现有视觉 SSM 都在 ImageNet 分类、COCO 检测、ADE20K 分割上评估。但这些是否足以展示 SSM 的优势？SSM 的线性复杂度在**高分辨率**任务（如 4K 图像、遥感图像、医学影像）上是否有更大优势？能否设计一个**专门展示 SSM 长序列优势的视觉基准**？

**Q37.** HydraMamba 将 SSM 用于 3D 点云。点云的核心挑战是**无序性**——没有固定的扫描顺序。除了四叉树/八叉树，还有哪些策略可以定义点云上的扫描？能否从图的角度（如 KNN 图、Delaunay 三角化）定义扫描顺序？
